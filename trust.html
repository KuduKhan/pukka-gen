SECURITY / DELIVERY

Practices worth inspecting.

These are the engineering expectations we aim to apply and verify within appropriately scoped engagements.

01 / DESIGN

Security by architecture

Define trust boundaries, data flows, access permissions and threat assumptions early.

02 / CODE

Reviewable engineering

Use version control, automated tests, code review and controlled dependency changes.

03 / EXPERIENCE

Accessible by design

Target keyboard navigation, readable contrast, responsive behavior and useful failure states.

04 / OPERATIONS

Release and recovery discipline

Define observable runtime behavior, rollback readiness and incident responsibilities for actual deployed systems.

PUBLIC / EVIDENCE

Check the actual artifacts.

The open-source website repository has executable build checks and browser QA scripts. An individual CI run evidences only the checks performed on that commit, not independent certification or any client deployment.

PRIVACY / ASSURANCE

Clear limits and responsible contact.

Website enquiries pass through a server-side email delivery process when configured. Legal notice, provider configuration, data handling and actual message receipt require operational verification.

Before sharing sensitive information

Do not include credentials, regulated records, customer data or confidential code in an initial public enquiry. Agree a suitable secure transfer and confidentiality process first.
